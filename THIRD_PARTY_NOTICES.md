# Third-party notices

Thorium Workspace is built on the crates and packages listed below. Each remains
under its own licence; nothing here is vendored or modified.

The complete, machine-generated dependency set with exact versions is in
`Cargo.lock` and `app/package-lock.json`, which are committed so a build is
reproducible.

## Thorium

Thorium itself is **not** bundled in this application, and no Thorium or Chromium
source is copied into this repository. The application downloads an official
portable Thorium build at runtime, at the user's request, from the upstream
project:

- Thorium — https://github.com/Alex313031/Thorium — a Chromium fork, BSD-3-Clause
  with the Chromium licence for the code it derives from.

The downloaded build stays a separate artefact inside the workspace folder and is
governed by its own licence.

## Standards

The one-time-password implementation follows published standards, and its tests
use the test vectors those documents publish:

- RFC 4226 — HOTP: An HMAC-Based One-Time Password Algorithm
- RFC 6238 — TOTP: Time-Based One-Time Password Algorithm
- The Key Uri Format for `otpauth://` URIs, as documented by the Google
  Authenticator project

## Icons

The application icon is original to this project and is generated by the script
recorded in the repository history. No third-party icon set is used; the eleven
interface glyphs are hand-written inline SVG paths in `app/src/components/Icon.tsx`.

## Regenerating this list

```sh
cargo tree --edges normal --prefix none | sort -u   # Rust dependency set
npm --prefix app ls --all --omit=dev                # frontend runtime set
```

Exact versions are in the committed lockfiles.
